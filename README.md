## 👨‍💻 Sobre mí

Soy **Ingeniero de Software / Desarrollador de Software** enfocado en el desarrollo de aplicaciones web, sistemas empresariales y soluciones digitales.

Me interesa transformar necesidades reales en productos de software funcionales, escalables y fáciles de mantener.

Actualmente trabajo y desarrollo proyectos utilizando tecnologías del ecosistema **PHP, Laravel, JavaScript, React, Node.js y bases de datos SQL**, además de herramientas modernas para despliegue, control de versiones y desarrollo colaborativo.

### 🎯 Actualmente me enfoco en

* Desarrollo de aplicaciones web modernas.
* Desarrollo **Full-Stack**.
* APIs REST y arquitectura de aplicaciones.
* Sistemas administrativos y empresariales.
* Diseño y gestión de bases de datos.
* Integración de servicios externos.
* Optimización, seguridad y buenas prácticas.
* Despliegue de aplicaciones y servicios en la nube.
* Aprendizaje continuo de nuevas tecnologías.
